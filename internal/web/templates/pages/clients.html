Installing it

  • Android: download the legacy .p12. Install it under Settings › Security › Encryption & credentials › Install a certificate › Wi-Fi certificate. Install the root CA separately as a "CA certificate", then choose it as the Wi-Fi CA.
  • Windows / macOS / iOS: the .p12 with the root included imports both in one step.
  • ClearPass: the issuing CA must be in the Trust List with usage EAP. Revoked certs appear on the CRL.
